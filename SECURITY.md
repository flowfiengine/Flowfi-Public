# Security reporting

Please **do not report vulnerabilities in public GitHub Issues** or include exploit details, credentials, private logs, or account information in public discussions.

If GitHub's **private vulnerability reporting** is enabled for this repository, use its private reporting feature. Otherwise, contact FlowFi maintainers through an established, verified private FlowFi communication channel. Share only the minimum detail needed to initiate a private conversation.

This repository does not contain the application source or infrastructure configuration. Public Issues are for product feedback and non-sensitive, publicly observable bugs only.
