# Community and contributions

Thanks for following FlowFi. We welcome thoughtful product feedback, accessibility suggestions, usability reports, and ideas for making crypto discovery more understandable.

## How to participate

1. Check existing Issues to avoid duplicates.
2. Open a **Feature request** to describe a problem, the user benefit, and a possible improvement.
3. Open a **Public bug report** only for problems observable in a publicly accessible FlowFi experience. Describe the behavior and expected result without disclosing private data.
4. Keep discussion respectful, factual, and focused on the product.

## Please do not post

- Credentials, API keys, seed/recovery phrases, wallet secrets, or private account information.
- Private dashboards, logs, internal endpoints, implementation details, or proprietary source code.
- Personal financial information, unreleased company information, or speculation presented as confirmed fact.
- Security vulnerabilities in a public Issue; see [SECURITY.md](SECURITY.md).

## Scope of this repository

This is a public development journal, not the FlowFi application source repository. We are not accepting application-code pull requests here. Documentation suggestions may be proposed via an Issue and incorporated after editorial and security review.

The maintainers may close, edit, or remove material that is unsafe, off-topic, promotional, or outside the public repository's scope.
